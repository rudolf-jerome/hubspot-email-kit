# HubSpot Email Kit

Reusable email assets for Harvest Yield outbound.

| File | Use |
|---|---|
| [signature.html](signature.html) | HTML email signature. Replace `LOGO_URL` with your hosted logo URL. |
| [touch-1-template.md](touch-1-template.md) | Touch 1 cold email, with HubSpot token fallbacks |

## Setup
1. **Signature:** HubSpot → Profile & Preferences → Email → Edit email signature → HTML. Paste `signature.html`.
2. **Template:** HubSpot → Sales → Templates → New. Paste the body, then add the tokens back with **Personalize** and set their fallbacks.
